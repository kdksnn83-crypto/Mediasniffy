## One Mission: Nasser Stahl

Eigenständiger Godot-Spielprototyp, Version 0.4: Brückensabotage, Trupp,
Gegner, Zug, Ballistik, zerstörbare Wachhütte, Granaten und Regen. Eigene
texturierte Low-Poly-Modelle für Gebäude, Wald, Soldaten, Gewehr und Zug.

### Download und Start unter Windows

1. [Fertiges Projekt-ZIP herunterladen](https://github.com/kdksnn83-crypto/Mediasniffy/raw/refs/heads/main/downloads/One-Mission-Nasser-Stahl-v0.4.zip).
   Alternativ oben **Code → Download ZIP** wählen.
2. ZIP vollständig entpacken.
3. Godot öffnen, **Importieren** wählen und `OneMission/project.godot` auswählen.
4. Projekt öffnen und **F5** drücken.

[Deutsche Startanleitung](OneMission/START_HIER.txt) ·
[Technik, Tests und Grenzen](OneMission/docs/TECHNIK.md)

Getestet mit Godot 4.6.3 (Compatibility): 108 Prüfungen bestanden.
Godot 4.7.2 und die Leistung auf dem Windows-Ziel-PC wurden nicht geprüft.
Die Grafik ist ein einfacher Prototyp; Ballistik und Materialwerte sind eigene
Spielmodelle und kein exakter Nachbau von Arma Reforger oder Battlefield.
